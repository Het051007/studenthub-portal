🛡️ Session Fixation Attack Mitigation Proof (CWE-384)

session_regenerate_id(true) Verified

In an unmitigated application, an attacker forces a victim to adopt an attacker-known session ID (e.g. via phishing link ?PHPSESSID=attacker_key). When the victim logs in, the attacker hijacks the session. In StudentHub, session_regenerate_id(true) purges the unauthenticated session file and produces a brand new token immediately upon login.
