3. Security Vulnerability Assessment (OWASP Top 10)

Threat / Vulnerability CWE Defensive Implementation in StudentHub Audit Status
SQL Injection (SQLi) CWE-89 100% Parameterized PDO queries with bound parameters. Emulated prepares disabled. Mitigated
Cryptographic Failures CWE-256 One-way Bcrypt hashing (PASSWORD_BCRYPT, cost 10) with 22-char dynamic salts. Mitigated
Session Fixation CWE-384 session_regenerate_id(true) called immediately upon credential validation. Mitigated
Cross-Site Request Forgery CWE-352 Cryptographically secure 32-byte tokens validated via hash_equals() on all POSTs. Mitigated
Cross-Site Scripting (XSS) CWE-79 Context-aware output escaping via htmlspecialchars($var, ENT_QUOTES, 'UTF-8'). Mitigated
Broken Access Control (RBAC) CWE-285 Strict server-side validation rejecting cross-role attempts with HTTP 403 Forbidden. Mitigated
Session Hijacking / Idle Leak CWE-613 Automated 300-second session expiration and hardened HttpOnly cookie attributes. Mitigated

4. Accessibility Audit (WCAG 2.1 Level AA)

  • Perceivable (Contrast Ratio): Text-to-background contrast ratio is 15.2:1 (Body) and 4.6:1 (Buttons), easily exceeding the 4.5:1 minimum threshold.
  • Perceivable (Information & Relationships): Semantic landmark tags (<header>, <nav>, <main>, <footer>) and explicit form label associations (<label for="...">).
  • Operable (Keyboard Navigation): Full keyboard navigability via Tab/Shift+Tab with high-contrast visible focus indicators (outline: 3px solid #38bdf8).
  • Understandable: Real-time password complexity guidelines and explicit feedback banners for all states.
  • Robust: ARIA labels on dynamic tables and role="alert" on error banners for screen readers.
